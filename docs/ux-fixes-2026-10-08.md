# October 8 UX fixes

This release addresses UX-01 through UX-14 from the local October 8 audit.
It keeps fees as manual host records: no checkout, money collection, or refunds.

- Known empty losers sources advance through byes; 3/5/6/7-player brackets and
  reset finals finish, with downstream undo coverage.
- Hosts can add walk-ups during Registration and Check-in. Door filters use
  persisted entry source. Capacity overflow says waitlisted. Required documents
  still prevent check-in; the player must review them.
- An optional copied private claim link transfers only an unused registration
  entry within 24 hours. Check-in, seeds, signatures, results, and duplicate
  event entries prevent transfer. Used history is never merged.
- Player calls precede fee details; paid details start collapsed. Pending
  results show host review rather than a new arrival warning. Resolved invites
  lead with entry, Review retains sticky Create, and mobile hosting has one-row
  section navigation and compact sorting/entrant details.
- Payment labels state the balance due. Mark paid in full fills the cumulative
  received amount for explicit confirmation; partial, waived, and correction
  fields remain available.
- Contextual host guidance, About & help, separate account access, single-scroll
  Options, selected-hover contrast, and stable invalid-code recovery are included.
